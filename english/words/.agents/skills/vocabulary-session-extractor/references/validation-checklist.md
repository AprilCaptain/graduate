# 归档验证清单

## 写入前

- [ ] 已读取项目 `AGENTS.md`（如存在）。
- [ ] 输入范围与用户指定范围一致，未扫描无关文件或日期。
- [ ] 已检查并兼容现有项目结构。
- [ ] 重复来源已读取来源游标，并在模型上下文之外裁剪已归档前缀；新来源使用独立游标。
- [ ] 已识别每个训练单元及其边界；同一天多次训练保持独立。
- [ ] 已读取“本次学习记录”或记录可靠的替代完成依据。
- [ ] 每个正式单元的训练日期有可靠来源；未使用当前日期或文件时间猜测。
- [ ] 每个正式单元的 `record_id` 由规范化内容稳定生成。
- [ ] 已读取状态文件、目标每日文件、相关单词详情和待变更单词对应的目录分片，未加载无关目录分片。
- [ ] 已同时使用 ID 与内容比较检查重复或更新关系。

## 内容校验

- [ ] 新词与复习词有可靠证据，未仅凭文件存在与否机械判断。
- [ ] 词形只在可靠时归并，未猜测不确定原形。
- [ ] 用户错误答案未写成正确知识。
- [ ] 词义、词性、搭配和句子确实来自本次训练。
- [ ] 每词每次通常不超过两个代表句，句子和搭配未重复。
- [ ] 结构分析简洁且围绕目标词，不逐词机械拆解。
- [ ] 掌握状态未因一次答对、看答案或猜对而夸大。
- [ ] 总结中的词数与实际提取数量已核对；差异未通过虚构内容消除。

## 文件校验

- [ ] 同一 `record_id` 在每日档案和状态中均无重复。
- [ ] 同一天既有训练的顺序和内容未被覆盖。
- [ ] 每日训练记录的“新学单词”使用“单词、核心含义”两列表格，不存在项目符号形式的单词条目。
- [ ] 不存在仅大小写不同的重复单词文件或目录条目。
- [ ] 新单词已插入正确字母分片的表格并按字母排序，总目录中的分片计数准确。
- [ ] 总目录保持为小型首字母导航表，没有展开全部单词。
- [ ] 每个 Markdown 相对链接指向真实文件。
- [ ] 所有修改后的 YAML front matter 和状态 YAML 可解析。
- [ ] 单词详情的核心词义表只包含“词性”和“核心含义”，不存在“本次语境”列。
- [ ] 单词详情不存在独立的“易错点”章节；必要提醒只保留在每日训练记录中。
- [ ] 人工备注、译文、释义、章节、标签和非标准有效内容均保留。
- [ ] 文件差异只包含当前归档所需的最小更新。
- [ ] 内容文件已先成功写入并验证，状态文件最后更新。
- [ ] 来源游标只推进到成功归档单元的结束消息，消息 ID、内容哈希和 `last_record_id` 一致。

## 幂等复查

重新计算同一输入的 `record_id`，并模拟或检查第二次执行：

- [ ] 不新增训练章节。
- [ ] 不重复学习记录、句子或搭配。
- [ ] 不重复目录条目。
- [ ] 相同单词再次运行目录更新脚本时，目标分片和总目录不产生差异。
- [ ] 同一持续来源没有新消息时，不产生归档或目录差异。
- [ ] 不改变既有训练顺序。
- [ ] 不产生仅由排序、空白或模板重写造成的差异。

## 完成报告

报告训练次数、训练日期、新增与更新单词数量、每日文件、目录和状态更新、数量差异、不确定项，以及重复、链接和格式检查结果。日期未确认、边界不清或词形不确定时明确说明，不将草稿报告为正式完成。
